# PostHog API — MCP server

Generated by `openapi2mcp` from `https://app.posthog.com/api/schema/?format=json`. Stdlib only, no dependencies.

## Run

```bash
export POSTHOG_TOKEN="<your token>"        # optional
export POSTHOG_BASE_URL="http://localhost:8000"             # optional override
python3 posthog_mcp_server.py                   # speaks MCP over stdio
```

## Client config (Claude Desktop / Cursor / any MCP client)

```json
{
  "mcpServers": {
    "posthog": {
      "command": "python3",
      "args": ["/absolute/path/to/posthog_mcp_server.py"],
      "env": { "POSTHOG_TOKEN": "<your token>" }
    }
  }
}
```
