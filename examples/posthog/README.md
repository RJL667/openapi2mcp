# PostHog API — MCP server

Generated by `openapi2mcp` from `https://app.posthog.com/api/schema/?format=json`. Stdlib only, no dependencies.

## Run

```bash
export POSTHOG_TOKEN="<your token>"        # optional
export POSTHOG_BASE_URL="https://app.posthog.com"             # optional override
python3 posthog_mcp_server.py                   # speaks MCP over stdio
```
