# OWASP Dependency-Track — MCP server

Generated by `openapi2mcp` from `https://raw.githubusercontent.com/DependencyTrack/dependency-track/main/api/src/main/openapi/openapi.yaml`. Stdlib only, no dependencies.

## Run

```bash
export DEPTRACK_TOKEN="<your token>"        # optional
export DEPTRACK_BASE_URL="/api/v2"             # optional override
python3 deptrack_mcp_server.py                   # speaks MCP over stdio
```

## Client config (Claude Desktop / Cursor / any MCP client)

```json
{
  "mcpServers": {
    "deptrack": {
      "command": "python3",
      "args": ["/absolute/path/to/deptrack_mcp_server.py"],
      "env": { "DEPTRACK_TOKEN": "<your token>" }
    }
  }
}
```

## Tools exposed (8)

| tool | endpoint | what it does |
|---|---|---|
| `listcomponents` | GET `/components` | List all components |
| `listprojectcomponents` | GET `/projects/{uuid}/components` | Retrieves a list of all components for a given project. |
| `getlatestvulndatasourcemirrorrun` | GET `/vuln-data-sources/{name}/mirror-runs/latest` | Get the latest vulnerability data source mirror run |
| `listvulnpolicies` | GET `/vuln-policies` | List vulnerability policies |
| `getvulnpolicy` | GET `/vuln-policies/{uuid}` | Get a vulnerability policy |
| `listvulnpolicybundles` | GET `/vuln-policy-bundles` | List vulnerability policy bundles |
| `getlatestvulnpolicybundlesyncrun` | GET `/vuln-policy-bundles/{uuid}/sync-runs/latest` | Get the latest vulnerability policy bundle sync run |
| `listvulnkevassertions` | GET `/vulns/{source}/{vuln_id}/kev-assertions` | Lists KEV assertions for a vulnerability |
