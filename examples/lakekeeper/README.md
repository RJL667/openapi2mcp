## Tools exposed (8)

| tool | endpoint | what it does |
|---|---|---|
| `listnamespaces` | GET `/v1/{prefix}/namespaces` | List namespaces, optionally providing a parent namespace to list underneath |
| `loadnamespacemetadata` | GET `/v1/{prefix}/namespaces/{namespace}` | Load the metadata properties for a namespace |
| `listtables` | GET `/v1/{prefix}/namespaces/{namespace}/tables` | List all table identifiers underneath a given namespace |
| `loadtable` | GET `/v1/{prefix}/namespaces/{namespace}/tables/{table}` | Load a table from the catalog |
| `loadcredentials` | GET `/v1/{prefix}/namespaces/{namespace}/tables/{table}/credentials` | Load vended credentials for a table from the catalog |
| `fetchplanningresult` | GET `/v1/{prefix}/namespaces/{namespace}/tables/{table}/plan/{plan-id}` | Fetches the result of scan planning for a plan-id |
| `listviews` | GET `/v1/{prefix}/namespaces/{namespace}/views` | List all view identifiers underneath a given namespace |
| `loadview` | GET `/v1/{prefix}/namespaces/{namespace}/views/{view}` | Load a view from the catalog |
